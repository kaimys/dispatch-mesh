# Status glyphs

Verbatim copies of the status glyphs Claude Design exported for the desktop app, from the wiki at `06_UX/icons/status/status-<state>-<light|dark>.svg` (design spec, *Glyphs*), copied on 2026-11-07 for US00012. The window shows the light or dark file through `<picture>` and `prefers-color-scheme`.

The reserved `paused-reserved` glyph is not copied; 0.3 has no paused state. When the design changes a glyph, copy the new file over the old one instead of editing it here.
